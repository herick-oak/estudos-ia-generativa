# 📚 Estudos de RAG (Retrieval-Augmented Generation)

Nesta pasta, documento meus estudos e experimentos práticos sobre RAG, a técnica que conecta LLMs a bases de conhecimento externas para evitar alucinações e fornecer respostas baseadas em fatos.

## 🛠️ Conceitos estudados aqui:
1. **Document Loaders:** Leitura de PDFs, CSVs ou textos.
2. **Text Splitting (Chunking):** Divisão do texto em partes menores com sobreposição (overlap).
3. **Embeddings:** Transformação de texto em vetores numéricos.
4. **Vector Stores:** Armazenamento e busca por similaridade (Cosine Similarity).
5. **Retrieval & Generation:** Orquestração com LangChain para buscar o contexto e gerar a resposta.
